# 🌸 「春」鑑賞ノート

ヴィヴァルディ《四季》より「春」第1楽章の鑑賞教材アプリです。
**先生が授業で使う**ことも、**生徒がひとりで取り組む**こともできます。

## 使い方
- `index.html` と `spring.mp3` を同じフォルダに置いて、`index.html` をブラウザで開く
  （GitHub Pages で公開すると、そのURLを開くだけで使えます）
- インストール・ネット接続は不要です
- URL の最後に `?mode=student` / `?mode=teacher` をつけると、そのモードで直接開きます

## 🧭 学びの軸
「なぜ、そう聞こえるの？」── 音楽のしくみ（音色・強弱・形式など）が、春の情景や気分をどのように生み出しているのかを、詩と結びつけながら探ります。

## 🧩 学ぶ内容は組み合わせ自由
授業時間に合わせて、内容を増やしたり減らしたりできます（先生用「🎯 ねらいとプラン」）。

| 内容 | 目安 | 1時間 | 2時間 | 3時間 |
|---|---|:-:|:-:|:-:|
| まず聴いてみよう（軸） | 10分 | ● | ● | ● |
| 詩と音楽（軸） | 15分 | ● | ● | ● |
| 場面あてクイズ | 10分 | | ● | ● |
| 主題をさがせ（軸） | 10分 | ● | ● | ● |
| 協奏曲ってなに？ | 15分 | | ● | ● |
| 楽器と奏法 | 15分 | | | ● |
| 音楽のしくみ | 15分 | | ● | ● |
| バロック時代の音楽 | 15分 | | | ● |
| 紹介文を書こう（軸） | 20分 | ● | ● | ● |

チェックを入れたり外したりして、自由に組み合わせることもできます。
選んだ内容に合わせて、次のものが自動で切りかわります。
- **使う知識**の一覧（音楽の要素と、用語・背景の知識に分けて表示）
- **高まる鑑賞の力**の表（聴き取る力／結びつける力／背景から味わう力／根拠をもって語る力／ほかの曲に生かす力）
- 学習指導要領との関わり（例）
- **指導の流れ**（50分ごとに自動で区切る）と評価の視点
- 生徒の画面のステップ、ワークシートの問題、最後のふりかえり

**生徒用リンク**（`?mode=student&plan=…`）を配ると、生徒の画面も同じ内容になります。

## 🧑‍🎓 ひとりで学ぶ
「はじめに」で学びの軸・使う知識・高まる力を確認してからステップに進みます。
どのステップにも「🎯 めあて／🔑 使う知識／🌱 高まる力」が表示されます。
書いた内容は端末（ブラウザ）に自動保存され、最後に印刷・PDF保存ができます。

## 🧑‍🏫 授業で使う
- 🎯 ねらいとプラン：内容の選択、知識・力の一覧、生徒用リンク
- 📺 提示画面：アニメーション＋場面名・詩・聴きどころ。「場面名をかくす」で問いかけ
- 📚 知識カード：協奏曲／楽器と奏法／バロック時代を大きく映して説明
- ❓ みんなでクイズ、🌸 主題さがしゲーム（クラス版）
- 📋 指導の流れ：選んだ内容から自動作成
- ⚙️ 設定：場面の時間合わせ、別の録音の読み込み、白紙ワークシート印刷
- キーボード：Space 再生／← → 場面移動／1〜0 場面ジャンプ／L くり返し／H かくす／F 大きく映す

## 音源
ルイス・カウフマン（独奏ヴァイオリン）、ヘンリー・スウォボダ指揮 コンサートホール室内管弦楽団（1947年録音）。
場面の時間はこの録音に合わせています。
