# 🌸 「春」鑑賞ノート

ヴィヴァルディ《四季》より「春」第1楽章の鑑賞教材アプリです。
**先生が授業で使う**ことも、**生徒がひとりで取り組む**こともできます。

## 使い方
- `index.html` と `spring.mp3` を同じフォルダに置いて、`index.html` をブラウザで開く
  （GitHub Pages で公開すると、そのURLを開くだけで使えます）
- インストール・ネット接続は不要です
- URL の最後に `?mode=student` / `?mode=teacher` をつけると、そのモードで直接開きます

## 🧭 学びの軸
「なぜ、そう聞こえるの？」── 音楽のしくみ（音色・強弱・形式など）が、春の情景や気分をどのように生み出しているのかを、詩と結びつけながら探ります。

## 📘 知識 と 💭 思考・判断・表現 の分け方
- **知識＝鑑賞のコツ**：「このように聴くと、曲の楽しみ方がよくわかる」と教えられるもの（7つ）
  - 🔊「こだま」をさがす（強弱）／🌸 主題の「おかえり」を待つ（形式）／🧱 音の「厚み」をくらべる（テクスチュア）／🎨 音の「絵」を見つける（音色・奏法）／〰️ 音の動きを指でなぞる（旋律）／🌥 同じ主題の「かげり」を聴く（調）／💬 かけ合いを「会話」として聴く（独奏と合奏）
- **思考・判断・表現＝4つのステップ**：👂知覚「何が聞こえた？」→ 💗感受「どんな感じ？」→ 🔍理由「なぜそう感じた？」→ ✍️表現「ことばや音で表そう」
- 先生用「🎧 鑑賞のコツ」タブに、コツごとの「▶ 聴いてみる」（いちばん分かりやすい部分の頭出し）と4ステップの発問例があります。
- 生徒用ステップ「聴き方のコツ」では、コツごとに4ステップで聴いて記録します。紹介文の「理由」も👂→💗→🔍の順で書く形にしています。

## 🧩 アプリの形：3つのコツで聴く（2時間扱い）
| | 先生が教える（知る） | 生徒が自分で考える | 活動 |
|---|---|---|---|
| ① 聴く | — | 感じたことをことばに | 通して聴く |
| ② コツ① 詩から想像する | ソネットと場面。**トリルとは**／**ヴァイオリンの高い音・低い音**（弦の太さ・指でおさえる長さ・楽器の大きさ）／**細かいくり返しと重なり**（合成音で聴き比べ、先生は大きく映せる） | 小鳥の声／川のせせらぎは、どんな音でできている？ | 絵とソネットの並べかえ、場面当て |
| ③ コツ② もどってくる主題 | リトルネッロ形式、6回の主題の調・長さ（楽譜から：ホ長調→ホ→ロ長調→嬰ハ短調→ホ→ホ） | 主題がもどると、なぜ効果的？ 嵐のあとが短調なのはなぜ？ | 主題の聴きくらべ、主題さがしゲーム |
| ④ コツ③ 独奏と全員のかけ合い | 独奏（Solo）とトゥッティ、f と p のこだま | 交代すると、なぜ生き生きする？ | 3D合奏、楽譜の Solo／Tutti の帯 |
| ⑤ 力試し：第3楽章 | — | 初めて聴く第3楽章で、3つのコツのどれが使えたか・どこでかを書く | 楽譜（Mutopia）から作った合成音で約50秒 |
| ⑥ まとめる | — | コツで書いたことを根拠に紹介文 | 印刷・バッジ |

### 鑑賞の力を伸ばすしかけ
- **もし〜だったら？**：楽譜から作った合成音で「楽譜どおり（A）」と「変えた版（B）」を聴きくらべる（小鳥に低い音を足す／川の細かい音をのばす／主題を消す／嵐のあとの主題を長調に／こだまを全部 f に／独奏を全員で）。どちらが合うか・なぜかを書く
- **自分のことばが先**：「何が聞こえた？」「どんな感じ？」は、まず自由に書き、「💡ことばのヒント」で選択肢を出す。「なぜ？」のヒントも押したときだけ
- **みんなのひとこと**：生徒の「ひとことで」を名前なしで先生の画面に集めて映す（連動と同じ中継サーバー）
- **体で表す**：主題がもどったら手を挙げる、川の音を指でなぞる、④では先生の画面に f／p を大きく出し、大きく・小さく手を動かす

- 「考える」はどれも 👂何が聞こえた？ → 💗どんな感じ？ → 🔍なぜ？ → ✍️ひとことで を1つずつ答える
- 先生の画面は進行バー①〜⑤。②〜④では右側に、そのコツの問い（③は主題6回の聴きくらべボタンも）が出る
- 3時間・4時間コースでは「もっと知る」（協奏曲の歴史・楽器と奏法・時代・音楽のしくみ）を足す

## 🧑‍🎓 ひとりで学ぶ
「はじめに」で学びの軸を確認し、ステップ1〜4へ。「📚 もっと知る」は左の一覧から好きなときに開く。
書いた内容は端末（ブラウザ）に自動保存され、最後に印刷・PDF保存ができる。

## 🏫 教室で使うときのしくみ
- **授業の進行バー**（先生の画面の上）：①聴く ②コツを知る ③コツで聴く ④まとめる を押すと、その段階に合った画面になり、進め方のひとことが出る
- **🔗 生徒用リンク**：進行バーの右。リンクで開いた生徒の端末は**授業中モード**（音を出さない。音は先生の画面から）。生徒は画面右上のボタンで「自分で聴く」に切りかえられる（イヤホン・家庭学習用）
- **名前を入れて始める**：前の人の記録が残っていると知らせ、「消して新しく始める」ボタンを出す。最後のページに「次の人のために記録を消す」
- **まとめる**：ステップ③で書いたことが並び、「使う」で理由の欄に入る
- 時間の目安：聴く8分・コツを知る8分・コツで聴く17分・まとめる12分（＋導入5分）

## 🔗 生徒の画面の連動
- 先生の端末が「いまの場面・再生位置・授業の段階」（数字だけ）を中継サーバーに送り、生徒用リンクで開いた端末がそれを受け取ってついてくる（場面・楽譜・3D・コツ、①〜④のステップ）
- 中継サーバーは ntfy（https://ntfy.sh、無料・登録不要）。設定で別のサーバーに変えられる。クラスごとに「部屋」を作り直せる
- 生徒は右上の「🔗 先生と連動中」を押すと、連動を止めて自分で動かせる。途中から開いた生徒も、いまの場面に合わせて始まる
- 注意：学校のネットワークで ntfy.sh が止められていると連動しない（そのときは生徒が「次の場面」で合わせる）。ntfy.sh は同じ回線からの同時接続数に上限がある（目安30）ので、40人のクラスでは全員がつながらないことがある

## 🧑‍🏫 授業で使う
タブは5つ：
- 📺 **授業画面**：情景／3D合奏、流れる楽譜、場面ボタン。右に**いまの場面のコツ**と発問例（👂何が聞こえた？ 💗どんな感じ？ 🔍なぜ？ ✍️ことばに）、聴きどころは折りたたみ
- 📚 **もっと知る**：鑑賞のコツ一覧／協奏曲・楽器・時代／写真／みんなでクイズ／主題さがしゲーム
- 🎯 **ねらいとプラン**：授業時間に合わせて「もっと知る」を選ぶ（4つのステップは固定）。知識・思考判断表現・高まる力・生徒用リンク
- 📋 **指導の流れ**：選んだ内容から自動作成
- ⚙️ **設定**：場面の時間合わせ、楽譜のずれ調整、別の録音、白紙ワークシート印刷
- キーボード：Space 再生／← → 場面移動／1〜0 場面ジャンプ／L くり返し／H かくす／F 大きく映す

## 🎼 楽譜を追いかける表示
- 情景アニメーション・3D合奏の下に、パート全体を1本の横長の楽譜にして、録音に合わせて右から左へ流す（再生線は左から3割の位置に固定、音部記号と調号は左に固定）。いまの音が光る。全パートで小節の幅をそろえているので、パートが自動で切りかわっても位置がずれない
- パート：自動（主題は第1ヴァイオリン、小鳥・嵐・見せ場は独奏）／独奏／第1Vn／第2Vn／ヴィオラ／低音／総譜（先生用）。3Dで楽器を押すとそのパートに切りかわる
- 楽譜の記号：スラー・フレーズのスラー・タイ・スタッカート・くさび形スタッカート・トリル・モルデント・フェルマータ・p／f、楽譜どおりの連桁と三連符、念押しの臨時記号（音の高さは別の変換ツールの結果と全音一致を確認）
- ヴィヴァルディが楽譜に書きこんだことば（Canto de gl'uccelli＝小鳥の歌、Scorrono i fonti＝泉が流れる、Tuoni＝雷、Solo／Tutti）と日本語訳を表示
- 楽譜データ：Mutopia Project「La Primavera」（Performers' Facsimiles の1725年初版をもとに LilyPond で入力、**CC BY-SA 3.0**）を、アプリ用の音符データ（`SCORE`）に変換。このデータ部分も CC BY-SA 3.0 です
- 録音との対応：楽譜から作った音と録音を照らし合わせ（クロマ特徴量＋DTW）、0.5拍ごとの時刻を求めた。ずれは先生用「設定」で全体を前後にずらせる
- 楽譜の描画に VexFlow を使う（`lib/` に同梱。なければネットから）

## 音源
