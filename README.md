# 🌸 「春」鑑賞ノート

ヴィヴァルディ《四季》より「春」第1楽章の鑑賞教材アプリです。
**先生が授業で使う**ことも、**生徒がひとりで取り組む**こともできます。

## 使い方
- `index.html` と `spring.mp3` を同じフォルダに置いて、`index.html` をブラウザで開く
  （GitHub Pages で公開すると、そのURLを開くだけで使えます）
- インストール・ネット接続は不要です
- URL の最後に `?mode=student` / `?mode=teacher` をつけると、そのモードで直接開きます

## 🧭 学びの軸
「なぜ、そう聞こえるの？」── 音楽のしくみ（音色・強弱・形式など）が、春の情景や気分をどのように生み出しているのかを、詩と結びつけながら探ります。

## 📘 知識 と 💭 思考・判断・表現 の分け方
- **知識＝鑑賞のコツ**：「このように聴くと、曲の楽しみ方がよくわかる」と教えられるもの（7つ）
  - 🔊「こだま」をさがす（強弱）／🌸 主題の「おかえり」を待つ（形式）／🧱 音の「厚み」をくらべる（テクスチュア）／🎨 音の「絵」を見つける（音色・奏法）／〰️ 音の動きを指でなぞる（旋律）／🌥 同じ主題の「かげり」を聴く（調）／💬 かけ合いを「会話」として聴く（独奏と合奏）
- **思考・判断・表現＝4つのステップ**：👂知覚「何が聞こえた？」→ 💗感受「どんな感じ？」→ 🔍理由「なぜそう感じた？」→ ✍️表現「ことばや音で表そう」
- 先生用「🎧 鑑賞のコツ」タブに、コツごとの「▶ 聴いてみる」（いちばん分かりやすい部分の頭出し）と4ステップの発問例があります。
- 生徒用ステップ「聴き方のコツ」では、コツごとに4ステップで聴いて記録します。紹介文の「理由」も👂→💗→🔍の順で書く形にしています。

## 🧩 学ぶ内容は組み合わせ自由
授業時間に合わせて、内容を増やしたり減らしたりできます（先生用「🎯 ねらいとプラン」）。

| 内容 | 目安 | 1時間 | 2時間 | 3時間 |
|---|---|:-:|:-:|:-:|
| まず聴いてみよう（軸） | 10分 | ● | ● | ● |
| 詩と音楽（軸） | 15分 | ● | ● | ● |
| 聴き方のコツ（軸） | 15分 | ● | ● | ● |
| 場面あてクイズ | 10分 | | | ● |
| 主題をさがせ | 10分 | | ● | ● |
| 協奏曲ってなに？ | 15分 | | ● | ● |
| 楽器と奏法 | 15分 | | | ● |
| 音楽のしくみ | 15分 | | ● | ● |
| バロック時代の音楽 | 15分 | | | ● |
| 紹介文を書こう（軸） | 20分 | ● | ● | ● |

チェックを入れたり外したりして、自由に組み合わせることもできます。
選んだ内容に合わせて、次のものが自動で切りかわります。
- **使う知識**の一覧（音楽の要素と、用語・背景の知識に分けて表示）
- **高まる鑑賞の力**の表（聴き取る力／結びつける力／背景から味わう力／根拠をもって語る力／ほかの曲に生かす力）
- 学習指導要領との関わり（例）
- **指導の流れ**（50分ごとに自動で区切る）と評価の視点
- 生徒の画面のステップ、ワークシートの問題、最後のふりかえり

**生徒用リンク**（`?mode=student&plan=…`）を配ると、生徒の画面も同じ内容になります。

## 🧑‍🎓 ひとりで学ぶ
「はじめに」で学びの軸・使う知識・高まる力を確認してからステップに進みます。
どのステップにも「🎯 めあて／🔑 使う知識／🌱 高まる力」が表示されます。
書いた内容は端末（ブラウザ）に自動保存され、最後に印刷・PDF保存ができます。

## 🧑‍🏫 授業で使う
- 🎯 ねらいとプラン：内容の選択、知識・力の一覧、生徒用リンク
- 📺 提示画面：アニメーション＋場面名・詩・聴きどころ。「場面名をかくす」で問いかけ
- 🎻 3D合奏（提示画面の切りかえ／生徒用「協奏曲ってなに？」）：独奏ヴァイオリン・第1/第2ヴァイオリン・ヴィオラ・チェロ・コントラバス・チェンバロの13人が録音に合わせて動く。弾いている人は足もとが光り、休んでいる人は楽器を下ろす。正面・真上・横の視点、名札を押すと楽器の写真。3Dはネット接続が必要（Three.js を読み込むため）
  - 楽器（3Dの奏者か名札）を押すと説明が開く：本物の写真、3Dで回せる楽器、楽器の解説、この曲での役割、ソネットのどのことばを表しているか（▶でその部分を再生）
  - 18世紀風の服装（かつら・上着・半ズボン）、バロック時代の楽器（エンドピンのないチェロ、なで肩のコントラバス、フランス式鍵盤のチェンバロ）、シャンデリアのある広間。休んでいる奏者は独奏者のほうを見る。「独奏に寄る」視点つき
- 📚 知識カード：協奏曲／楽器と奏法／バロック時代を大きく映して説明
- 📷 写真：楽器・演奏形態・作曲者の写真を大きく映す（「ここを見よう」つき）。先生の端末で自分の写真に差しかえることもできます（`photos/README.md`）
- ❓ みんなでクイズ、🌸 主題さがしゲーム（クラス版）
- 📋 指導の流れ：選んだ内容から自動作成
- ⚙️ 設定：場面の時間合わせ、別の録音の読み込み、白紙ワークシート印刷
- キーボード：Space 再生／← → 場面移動／1〜0 場面ジャンプ／L くり返し／H かくす／F 大きく映す

## 🎼 楽譜を追いかける表示
- 情景アニメーション・3D合奏の下に、いま演奏している2小節の楽譜を表示。いまの音が光り、線が進む
- パート：自動（主題は第1ヴァイオリン、小鳥・嵐・見せ場は独奏）／独奏／第1Vn／第2Vn／ヴィオラ／低音／総譜（先生用）。3Dで楽器を押すとそのパートに切りかわる
- ヴィヴァルディが楽譜に書きこんだことば（Canto de gl'uccelli＝小鳥の歌、Scorrono i fonti＝泉が流れる、Tuoni＝雷、Solo／Tutti）と日本語訳を表示
- 楽譜データ：Mutopia Project「La Primavera」（Performers' Facsimiles の1725年初版をもとに LilyPond で入力、**CC BY-SA 3.0**）を、アプリ用の音符データ（`SCORE`）に変換。このデータ部分も CC BY-SA 3.0 です
- 録音との対応：楽譜から作った音と録音を照らし合わせ（クロマ特徴量＋DTW）、0.5拍ごとの時刻を求めた。ずれは先生用「設定」で全体を前後にずらせる
- 楽譜の描画に VexFlow（ネットから読み込み）を使うため、表示にはネット接続が必要

## 音源
ルイス・カウフマン（独奏ヴァイオリン）、ヘンリー・スウォボダ指揮 コンサートホール室内管弦楽団（1947年録音）。
場面の時間はこの録音に合わせています。
