# 🌸 「春」鑑賞ノート

ヴィヴァルディ《四季》より「春」第1楽章の鑑賞教材アプリです。
**先生が授業で使う**ことも、**生徒がひとりで取り組む**こともできます。

## 使い方
- `index.html` と `spring.mp3` を同じフォルダに置いて、`index.html` をブラウザで開く
  （GitHub Pages で公開すると、そのURLを開くだけで使えます）
- インストール・ネット接続は不要です
- URL の最後に `?mode=student` / `?mode=teacher` をつけると、そのモードで直接開きます

## 🧭 学びの軸
「なぜ、そう聞こえるの？」── 音楽のしくみ（音色・強弱・形式など）が、春の情景や気分をどのように生み出しているのかを、詩と結びつけながら探ります。

## 📘 知識 と 💭 思考・判断・表現 の分け方
- **知識＝鑑賞のコツ**：「このように聴くと、曲の楽しみ方がよくわかる」と教えられるもの（7つ）
  - 🔊「こだま」をさがす（強弱）／🌸 主題の「おかえり」を待つ（形式）／🧱 音の「厚み」をくらべる（テクスチュア）／🎨 音の「絵」を見つける（音色・奏法）／〰️ 音の動きを指でなぞる（旋律）／🌥 同じ主題の「かげり」を聴く（調）／💬 かけ合いを「会話」として聴く（独奏と合奏）
- **思考・判断・表現＝4つのステップ**：👂知覚「何が聞こえた？」→ 💗感受「どんな感じ？」→ 🔍理由「なぜそう感じた？」→ ✍️表現「ことばや音で表そう」
- 先生用「🎧 鑑賞のコツ」タブに、コツごとの「▶ 聴いてみる」（いちばん分かりやすい部分の頭出し）と4ステップの発問例があります。
- 生徒用ステップ「聴き方のコツ」では、コツごとに4ステップで聴いて記録します。紹介文の「理由」も👂→💗→🔍の順で書く形にしています。

## 🧩 アプリの形：「聴き方が身につく」4つのステップ ＋ もっと知る
芯は「鑑賞のコツ（知識）を使って、4つのステップ（思考・判断・表現）で聴く」こと。ほかの機能はそれを支える道具です。

| | 内容 | 目安 |
|---|---|---|
| ステップ1 | **聴く**：何も知らずに聴き、感じたことを書く | 10分 |
| ステップ2 | **コツを知る**：7つのコツを ▶ で聴いて確かめる | 10分 |
| ステップ3 | **コツで聴く**：情景／3D合奏・流れる楽譜を見ながら、**いまの場面で使えるコツが自動で出る**。👂→💗→🔍→✍️で書く | 15分 |
| ステップ4 | **まとめる**：紹介文とふりかえり | 15分 |
| 📚 もっと知る | 詩と音楽／主題をさがせ／場面あてクイズ／音楽のしくみ／協奏曲／楽器と奏法／バロック時代（先生がプランで選ぶ） | 各10〜15分 |

- 1時間＝4つのステップだけ、2時間＝＋詩と音楽・主題さがし・協奏曲、3時間＝もっと知るをすべて。
- 先生の「授業画面」も同じ考え方：右側に「いまの場面のコツ」と4ステップの発問例が自動で出る。

## 🧑‍🎓 ひとりで学ぶ
「はじめに」で学びの軸を確認し、ステップ1〜4へ。「📚 もっと知る」は左の一覧から好きなときに開く。
書いた内容は端末（ブラウザ）に自動保存され、最後に印刷・PDF保存ができる。

## 🧑‍🏫 授業で使う
タブは5つ：
- 📺 **授業画面**：情景／3D合奏、流れる楽譜、場面ボタン。右に**いまの場面のコツ**と発問例（👂何が聞こえた？ 💗どんな感じ？ 🔍なぜ？ ✍️ことばに）、聴きどころは折りたたみ
- 📚 **もっと知る**：鑑賞のコツ一覧／協奏曲・楽器・時代／写真／みんなでクイズ／主題さがしゲーム
- 🎯 **ねらいとプラン**：授業時間に合わせて「もっと知る」を選ぶ（4つのステップは固定）。知識・思考判断表現・高まる力・生徒用リンク
- 📋 **指導の流れ**：選んだ内容から自動作成
- ⚙️ **設定**：場面の時間合わせ、楽譜のずれ調整、別の録音、白紙ワークシート印刷
- キーボード：Space 再生／← → 場面移動／1〜0 場面ジャンプ／L くり返し／H かくす／F 大きく映す

## 🎼 楽譜を追いかける表示
- 情景アニメーション・3D合奏の下に、パート全体を1本の横長の楽譜にして、録音に合わせて右から左へ流す（再生線は左から3割の位置に固定、音部記号と調号は左に固定）。いまの音が光る。全パートで小節の幅をそろえているので、パートが自動で切りかわっても位置がずれない
- パート：自動（主題は第1ヴァイオリン、小鳥・嵐・見せ場は独奏）／独奏／第1Vn／第2Vn／ヴィオラ／低音／総譜（先生用）。3Dで楽器を押すとそのパートに切りかわる
- 楽譜の記号：スラー・フレーズのスラー・タイ・スタッカート・くさび形スタッカート・トリル・モルデント・フェルマータ・p／f、楽譜どおりの連桁と三連符、念押しの臨時記号（音の高さは別の変換ツールの結果と全音一致を確認）
- ヴィヴァルディが楽譜に書きこんだことば（Canto de gl'uccelli＝小鳥の歌、Scorrono i fonti＝泉が流れる、Tuoni＝雷、Solo／Tutti）と日本語訳を表示
- 楽譜データ：Mutopia Project「La Primavera」（Performers' Facsimiles の1725年初版をもとに LilyPond で入力、**CC BY-SA 3.0**）を、アプリ用の音符データ（`SCORE`）に変換。このデータ部分も CC BY-SA 3.0 です
- 録音との対応：楽譜から作った音と録音を照らし合わせ（クロマ特徴量＋DTW）、0.5拍ごとの時刻を求めた。ずれは先生用「設定」で全体を前後にずらせる
- 楽譜の描画に VexFlow（ネットから読み込み）を使うため、表示にはネット接続が必要

## 音源
ルイス・カウフマン（独奏ヴァイオリン）、ヘンリー・スウォボダ指揮 コンサートホール室内管弦楽団（1947年録音）。
場面の時間はこの録音に合わせています。
