# 写真フォルダ

このフォルダに次の名前で写真（JPEG）を入れると、アプリの中に自動で表示されます。
写真がないところは「写真を準備中」と表示されます。

| ファイル名 | 内容 |
|---|---|
| violin.jpg | ヴァイオリン |
| viola.jpg | ヴィオラ |
| cello.jpg | チェロ |
| contrabass.jpg | コントラバス |
| harpsichord.jpg | チェンバロ（ハープシコード） |
| concerto.jpg | 協奏曲の演奏（独奏者とオーケストラ） |
| strings.jpg | 弦楽合奏（室内オーケストラ） |
| continuo.jpg | 通奏低音（チェンバロと低音楽器） |
| vivaldi.jpg | ヴィヴァルディの肖像 |
| venice.jpg | ヴェネツィアの街 |

- 横長（4:3くらい）の写真がきれいに収まります。
- 写真の出典（撮影者・ライセンス）は、`index.html` の `PHOTOS` の `credit:""` に書くと、大きく映したときに表示されます。
- 公開するリポジトリに入れる写真は、自由に使ってよいもの（パブリックドメインやクリエイティブ・コモンズなど）にしてください。
